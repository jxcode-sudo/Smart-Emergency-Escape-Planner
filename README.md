# Smart Emergency Escape Planner

A GUI-based Design and Analysis of Algorithms project that finds minimum-cost escape routes using Dijkstra's shortest-path algorithm.

## Features
- Interactive building map
- Shortest-path calculation
- Block and reopen corridors
- Automatic route recalculation
- Visual display of the selected route and algorithm steps

## Technologies
- Python
- Tkinter
- NetworkX
- Matplotlib

## Installation

Install the required libraries:

```bash
python -m pip install -r requirements.txt
```

Run the application:

```bash
python smart_escape_planner.py
```

## Algorithm Complexity
- Time: O((V + E) log V)
- Space: O(V + E)

V represents locations and E represents corridors.
